# Retro Currency — Android project

Это исходный Android-проект, который GitHub Actions автоматически собирает в APK.

## Как загрузить с телефона
1. Создайте пустой репозиторий на https://github.com/new (название, например `retro-currency`).
2. В репозитории нажмите **Add file → Upload files**.
3. Распакуйте этот ZIP на телефоне и загрузите **содержимое папки проекта**, включая скрытую папку `.github`.
   В корне репозитория должны быть `settings.gradle`, `build.gradle`, `app/` и `.github/`.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Дождитесь зелёной галочки у `Build Android APK`.
6. Откройте завершившийся запуск, внизу найдите **Artifacts** и скачайте `retro-currency-apk`.
7. Распакуйте скачанный artifact ZIP и установите `app-debug.apk` на Android. При запросе разрешите установку из этого источника.

## Что в приложении
- USD → UZS → RUB, по умолчанию 1 USD.
- Изменение любого поля пересчитывает остальные.
- Калькулятор изменяет активную валюту.
- Курс запрашивается при запуске из open.er-api.com и сохраняется локально.
- При отсутствии сети используется последний сохранённый курс.

Первый APK будет debug-сборкой для личной установки, не публикационной подписанной сборкой Google Play.
